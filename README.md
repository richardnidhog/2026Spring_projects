# Monte Carlo Simulation of Hospital Bed Capacity Under Surge Conditions

**Team Member:** Xujun Zhou  
**Project Type:** Type I

## Overview

This project critiques and improves a 2020 Monte Carlo simulation that modeled COVID-19-driven hospital bed capacity overload in the Chicago area using a SEIR framework. The original contained critical coding errors that caused the susceptible population to never change, breaking the model's core logic. This project fixes those errors and extends the simulation with two new surge scenarios.
